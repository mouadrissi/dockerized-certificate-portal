# 🎓 Certificate and Attestation Management Portal (PFA)

This project is a modern web application developed with **Django**, designed to automate the generation, management, and verification of academic and professional certificates. It features a **QR Code** validation system and is fully containerized using **Docker** for seamless deployment.

## 🚀 Key Features
- **Automated Generation:** Creation of PDF certificates with dynamic data integration.
- **Security & Verification:** Each certificate includes a unique QR Code to verify its authenticity online.
- **Role-Based Access Control (RBAC):** Secure user roles management (Administrators, Students, Partners).
- **Optimized UI/UX:** Modern, intuitive, and user-friendly interface.
- **Seamless Deployment:** Full orchestration and containerization via Docker Compose.

## 🛠️ Tech Stack
- **Backend:** Python, Django 5.x
- **Database:** SQLite (Development) / MySQL (Production Ready)
- **Frontend:** HTML5, CSS3, JavaScript (Django Templates)
- **DevOps & Containerization:** Docker, Docker Compose
